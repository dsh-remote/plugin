# 0.6 界面设计

视觉基线沿用 0.5 小程序主题。复用同样的浅色和深色 token 表，保持前景、容器、按钮、告警、字号、间距和圆角的命名与取值。构建从主题文件解析导航栏和回弹区颜色。

| 语义 | 浅色 | 深色 |
| --- | --- | --- |
| 页面底 | #EFF2F7 | #0A0B10 |
| 卡片底与原生导航栏 | #FFFFFF | #141822 |
| 下沉面 | #E5EBF5 | #1C2130 |
| 主操作 | #2F4BD6 | #3F5BF6 |

会话页把联机状态、待处理和项目会话依次摆在同一列。未配对时在联机区提供扫码入口。聊天页把指令、工具结果和回复排在时间线上，待处理项和审批卡使用旧版品牌浅底，浅色 #F2F3FF，深色 #1B2F51。输入区使用旧版下沉面和圆角。宿主远程控制面板提供配对、核对码与连接设置。

新版分组、聊天和配对交互由 0.6 实现。旧版设计 token 的两个主题文件原样迁入 packages/client/theme。自动用例校验颜色和尺寸，微信模拟器校验实际主题、导航和布局。
