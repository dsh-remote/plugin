## 用例如何发现错误

开始实现前先运行各组契约。四种变异在独立临时副本中使各自的行为用例失败。

- 取消新签令牌保护后，新主机领到令牌仍不能通过鉴权。
- 允许第二份授权覆盖正在展示的授权后，手机无法用显示过的核对码对应的密钥正常通信。
- 把慢速档等候缩成普通冷却后，令牌重领提前触发。
- 取消 Markdown 装载兜底后，解析故障无法降级显示正文。

微信模拟器检查先抓到了浅色根容器被状态圆点样式压窄的问题，也确认了旧暖色确实落在待处理行。调整后分别复查了根容器宽度、列表和聊天的待处理背景，以及实际页面跳转。
