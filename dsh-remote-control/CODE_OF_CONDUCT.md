# 贡献者公约（行为准则）

## 我们的承诺

我们作为成员、贡献者与领导者，承诺让每个人参与本社区的体验都不受骚扰，无论其年龄、体型、
可见或不可见的残障、族裔、性征、性别认同与表达、经验水平、教育程度、社会经济地位、国籍、
外貌、种族、宗教或性取向。

我们承诺以有助于营造开放、友好、多元、包容且健康社区的方式行事与互动。

## 我们的标准

有助于营造积极环境的行为示例：

- 对他人展现同理心与善意
- 尊重不同的意见、观点与经验
- 给予并优雅地接受建设性反馈
- 承担责任，为我们的错误向受影响者道歉，并从中学习
- 关注的不仅是个人利益，还有整个社区的利益

不可接受的行为示例：

- 使用性化的语言或意象，以及任何形式的性关注或性挑逗
- 挑衅、侮辱或贬损性评论，以及人身或政治攻击
- 公开或私下的骚扰
- 未经明确许可发布他人的隐私信息，例如住址或邮箱
- 其他在专业场合可被合理视为不当的行为

## 执行责任

社区领导者负责阐明并执行我们的可接受行为标准，并会针对任何被认为不当、具威胁性、冒犯性或
有害的行为采取适当且公正的纠正措施。

社区领导者有权也有责任移除、编辑或拒绝不符合本行为准则的评论、提交、代码、wiki 编辑、issue
及其他贡献，并会在适当时说明管理决定的理由。

## 适用范围

本行为准则适用于所有社区空间，也适用于个人在公共场合正式代表社区的情形。

## 执行

辱骂、骚扰或其他不可接受行为可向负责执行的社区领导者通过 GitHub
（[@providcc](https://github.com/providcc)）举报。所有投诉都会得到及时、公正的审查与调查。

所有社区领导者都有义务尊重任何事件举报者的隐私与安全。

## 执行指引

社区领导者在判定任何其认为违反本行为准则的行为后果时，会遵循以下社区影响指引：

### 1. 纠正

**社区影响**：使用了不当语言或其他在社区中被视为不专业或不受欢迎的行为。

**后果**：由社区领导者私下书面警告，说明违规性质并解释为何该行为不当。可能会要求公开道歉。

### 2. 警告

**社区影响**：通过单次事件或一系列行为造成的违规。

**后果**：警告并说明若继续该行为将有的后果。在指定时间内不得与相关人员互动，包括主动与执行
行为准则者互动。这包括避免在社区空间以及社交媒体等外部渠道的互动。违反这些条款可能导致临时
或永久封禁。

### 3. 临时封禁

**社区影响**：严重违反社区标准，包括持续的不当行为。

**后果**：在指定时间内临时禁止与社区进行任何形式的互动或公开交流。在此期间不得与相关人员有任何
公开或私下互动，包括主动与执行行为准则者互动。违反这些条款可能导致永久封禁。

### 4. 永久封禁

**社区影响**：表现出违反社区标准的模式，包括持续的不当行为、对个人的骚扰，或对某类群体的侵犯
或贬损。

**后果**：永久禁止在社区内进行任何公开互动。
