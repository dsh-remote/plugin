## 两条新的判据纪律（本轮踩到）

1. **`String(fn)` 会丢掉参数名** —— 想从已加载的函数反查签名会拿到
   `function () { … }`，正则取到的"第一参"是 `function`，一次产出 17 个假阳性。
   要读源码文本。
2. **变异必须能编译** —— `if (peer.protocol === undefined && !peer.countedProtocol)`
   改成 `if (true)` 时 `else if` 变成不可达分支，**tsc 直接红**，判据根本没跑。
   换成"删掉闩锁置位"才测得出真东西。这与 memory 里已有的那条同族。
