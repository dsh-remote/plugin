# 2026-10-04：Markdown 渲染（mp）

## 调研：没有直接可用的开源方案，四个候选全否

用户要求「找开源项目，不要自己写（覆盖不全）」。实调网络核实：

| 库 | 体积 | 否掉的原因 |
|---|---|---|
| `@ant-design/x-markdown-mini` 1.1.0 | 34.3K gz | 组件是 **`.axml`**（支付宝语法），微信不可用；且输出私有格式，仍要转换层 |
| `mp-html` 的 `parser.js` | 10.6K gz | 输出确实是 nodes，但要配 `marked` 出 HTML 再中转 |
| `marked` v18.0.14 | 14.3K gz | 只出 HTML/toToken，**token→nodes 那层还得自己写** |
| `towxml` / `wemark` / `wxParse` | — | 输出 WXML 结构（非 nodes）；wemark 停更 2023 且**无 License**；wxParse 已死 |

**最终：`marked`（只调 `lexer()`）+ 自写 token→nodes**。语法解析交给成熟实现，
渲染层归我们（因为只有我们知道 rich-text 的限制在哪）。

⚠️ **npm 上没有 `mp-html-parser` 这个包**（实测 404），网上文章全错；
`x-markdown-mini` 官方 `marked.min.js` 是 **ESM**（尾部 `export{}`），小程序 require 直接崩。

## rich-text 的三条硬限制（都实测过）

① **标签白名单**：白名单外的标签被**直接丢掉**（内容凭空消失，界面上看不出原因）→ 只能生成白名单标签 + `prune()` 兜底。
② **不认外部 class**：`attrs.class` 只在自定义组件 wxss 里生效 → 样式全走 inline style，
   **且颜色解析成具体色值**（`var(--x)` 会让深色下字色不变 —— 本项目真机踩过）。
   `check-mp-contrast` 只扫 wxss、看不见 inline style，所以 `PALETTE` 在判据里**自带对比度自证**。
③ **内部不能滚动**：表格必须 `splitTables()` 摘出来由 WXML 侧包 `scroll-view`；
   代码块没法拆（会打乱正文流），改用 `word-break` 折行。
   列宽固定（`COL_W=240`）+ 每格 `word-break:break-all`，「列数×COL_W」才成立。

## 流式：跳变的根因与办法

实测逐字输入 `a **粗体** b`（**不缓冲**时）：
`"a **粗体"`→`"a **粗体"` → `"a **粗体*"`→**`"a *"`**（文字倒退）→ `"a **粗体**"`→`"a 粗体"`。

办法 = `pendingFrom()` 扣住尾部未配对的标记。缓冲后第 7/8 帧内容字都是 `a粗体`，
只是星号消失、加粗补上 —— **文字无倒退**。

### 三个非直觉的坑（都踩过）

① **围栏靠"数配对"必错**：末尾 16 字符窗口**看不到行首那个开始 ```**，两个 ``` 数成 1 次
   → 判成未闭合 → **done 后 pending 还非空**。必须数**行首围栏总数**（`lastLineFence()`）。
   ⚠️ 且不能用 `lastIndexOf` 找"开始的"—— 那会找到**闭合那个**，往后找配对必然失败。
② **围栏的反引号污染行内配对**：闭合围栏的 ``` 被 `` ` `` 数成 3 次（奇数）→ 又判未闭合。
   修法：先切掉围栏那一整行，再数后面的行内标记。
③ **`from = 0` 的歧义**：「不用扣」与「从第 0 字扣起」撞在一起，调用方 `from > 0 ? …` 分不清
   → 流式期第一段一个字都不显示。**用 `-1` 表示"不用扣"**。

### 已知且接受的偏差（别当 bug 重新"修"）

围栏**未闭合**时 marked 会把 `` ```js `` 的 `js` 当语言标记丢掉（`render("```js\nc")`→`"c"`），
代码内容一字不差。

## 这轮最值钱的一条：判据红过 ≠ 判据抓得住

我先写「内容字单调增长」，反证（关掉缓冲）时**它没红**。查下去：
第 7/8 帧内容字都是 `a粗体`（**相同**），真正跳变的是那个 `*`。
补了「标记符号本身也不许中途消失」才在破坏态下真红。

e2e 那 4 条也踩了**破坏没生效**：把 `b.done` 改成 `b.done && !b.done`
（恒 false → 反而**打开**了流式），129 全绿，差点当成"判据无效"。

判据自身还修了三处**不是实现锅**的错：`shown()` 漏算 `split.tables` 的表格、
缓冲区长度用绝对阈值、「纯空白」两条判据自相矛盾。

**判据自身红时，必须逐条查清是判据错还是实现错**，别一律归给实现。

## 反过来的经验：`cd` 在 Bash 工具里不跨调用生效

每次 Bash 调用都是新 shell —— 写 `cd X && python3 …` 时 Python 里的相对路径会
落到别处，报 `FileNotFoundError`（我据此差点以为"破坏没生效"）。
**写文件用绝对路径**，或在同一行里 `cd` 且确认后续命令的工作目录。

# 2026-10-04 清晨：抓到一个「全绿但界面上是空的」真缺陷

## 上一轮留下的两个未验证项，动手验的第一件就爆了

上一轮 markdown 落地后，判据全绿（单测 30 / e2e 129 / 对比度 260），
但我明确记了「真机上的深色 inline style 视觉效果未自动验证」。这次去验，
**截图上正文整段是空的** —— `.reply` 只剩 36px（纯 padding），
`.md-body` 的 `size().height` 是 **0**。

## 根因：`rich-text` 的 `nodes` 不能绑 `wx:for` 作用域里的变量

`nodes="{{item.mdParts[i]}}"` 与 `nodes="{{part}}"`（循环项）都渲染成**高度 0 的空块**。
逐档实测（不是猜的）：

| 绑定 | 结果 |
|---|---|
| `{{topLevelField}}`（纯顶层字段） | ✅ |
| `{{mdMap[item.key]}}`（顶层 map + **一层**索引） | ✅ |
| `{{mdBodies[item.key][pi]}}`（**两层**索引） | ❌ 0 |
| `{{part}}`（`wx:for` 循环项） | ❌ 0 |

**逐个排除的嫌疑**（都别再查一遍）：自闭合标签（`<rich-text/>` vs `</rich-text>`
无差别）、`wx:key="index"`、`wx:else`、wxss（`line-height` 读出来 = 1.65×字号，
说明 wxss 生效了；**同一位置**换字面量 nodes 立刻正常，所以不是样式压成 0）。
**官方文档与社区都查不到这条** —— 只能实测。

## 修法与它的代价

① `_withMd` 把 nodes 挂到块的 `_md`，`_commit` 每次**整份重建**进顶层
`mdBodies[块key]`，wxml 写 `nodes="{{mdBodies[item.key]}}"`（一层索引）。
② **表格不再摘出去**包 `scroll-view` 横滚 —— 那必然要两层索引。
`tableNode` 改成**列宽按容器百分比平分**（`100/列数`% + `min-width:120rpx`）。
`splitTables()` 函数留着（备用接法，判据还守着），但 chat 页不再调。
③ 顺手补了 `_retheme()`：`onShow` 里比一次 `theme.current()`，变了就重排全部正文块
—— **markdown 颜色是烘焙进 nodes 的**，而切主题的按钮在 sessions 页。

## 三个新踩的坑（都写进 skill 了）

- **判据依赖的全局状态必须先归一**。主题存 `wx` 本地存储、跨探针共享；
  上一轮留在深色，下一轮 `onToggleTheme` 就切回浅色 → 判据报 `themeName=light`，
  **假红且与被测代码无关**。我反证 `_retheme` 时 5 条一起红，差点当成"我改坏了"。
- **`reLaunch` 作废所有旧 page 句柄**（报 `page is not on top of page stack`）；
  `navigateBack` 后探针**不会替你调 `onShow`** —— 要验挂在 onShow 里的逻辑得自己调。
- **automator 的 API 缺口**：`page.screenshot` / `page.evaluate` / `mini.evaluate`
  **都不存在**（截图用 `miniProgram.screenshot`）；`el.text()` 对 `rich-text`
  **返回空串**（不是没内容，看 `size().height`）；`el.scrollWidth` 不是函数。
- **IDE 端口连不上时别改代码**：`cli quit` 后 `cli auto` 会报
  `IDE may already started at port 27267` 而起不来（残留 Electron 占端口）。
  `pkill -9 -f wechatwebdevtools` 后再起；**或者干脆用 `automator.launch()`
  自己拉**（它会 spawn cli 并轮询端口，比手动 `cli auto` 可靠）。
  验证 `curl 127.0.0.1:9420/json/version` 返回 **426** 才算通（200/502 都不算）。

## 判据侧：两条新探针都反证过，且反证是"精准变红"

- `md`：注入两层索引 → **只有高度那条红**（0px），其余 4 条仍绿。
- `md-dark`：让 `_retheme` 永不重排 → **只有「nodes 重算」那两条红**，
  「切到深色」「挂 class」仍绿（破坏没碰它们）。
这两次都符合「反证要看的是我这次改动的那一条」，而不是"红一片才算抓住"。

`npm run check` 32/32、`e2e --test` 43/43、探针 11 组（新增 `md` / `md-dark`）。
